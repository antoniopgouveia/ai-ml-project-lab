## 🧠 Methods & Techniques

This portfolio covers a progression from **foundational machine learning to modern deep learning and LLM engineering**.

### 📈 Regression & Classification

Traditional supervised learning using:

* Linear and logistic regression
* Decision trees
* Random Forest
* XGBoost
* Feature engineering and model evaluation

### 🧠 Artificial Neural Networks (ANNs)

Feedforward neural networks for structured-data problems, ranging from predictive modeling to feature representation learning.

Technologies and tools include:

* **TensorFlow**
* **PyTorch**
* **Weights & Biases**
* **MLflow**

### 🩻 Convolutional Neural Networks (CNNs)

Image classification and medical imaging applications, including:

* Multi-label disease detection
* Transfer learning
* Model interpretability with **Grad-CAM**
* Pre-trained architectures such as:

  * DenseNet
  * ResNet
  * EfficientNet

### 🔄 Recurrent Neural Networks (RNNs)

Sequential data modeling for:

* Time-series forecasting
* Anomaly detection
* Sequence-to-sequence tasks
* Temporal pattern analysis

Architectures include:

* LSTMs
* GRUs
* Encoder-decoder architectures

Applications span business metrics and clinical text.

### 📝 Natural Language Processing (NLP)

Natural language processing applied to both general and biomedical domains, including:

* Text classification
* Named entity recognition
* Relation extraction
* Biomedical NLP
* Clinical language understanding

Transformer models explored include:

* BERT
* PubMedBERT
* BioLinkBERT

### 🔎 Retrieval-Augmented Generation (RAG)

LLM engineering with retrieval pipelines, including:

* Embedding-based search
* Vector databases and stores
* ChromaDB
* FAISS
* Citation-aware generation
* RAG evaluation

Evaluation frameworks include:

* RAGAS
* ROUGE
* BERTScore

Projects are deployed as interactive applications using **Streamlit** and **Gradio** where appropriate.

## 🔬 Approach & Philosophy

Every project in this repository follows the same principles:

### 🎯 Problem First

Each project starts with a **real question**, not a technique in search of a dataset.

### 🔁 Reproducible by Default

**Clone → Install → Run.**

Projects aim to minimize hidden steps and undocumented dependencies so that experiments can be reproduced and extended.

### 📊 Honest Evaluation

Models are compared against meaningful baselines using appropriate metrics, including:

* Accuracy
* F1 score
* ROUGE
* AUC-ROC
* Latency

Where relevant, projects also include **failure analysis** to understand where and why models perform poorly.

### 🚀 Deployment-Ready

Where feasible, projects include live demonstrations deployed through platforms such as:

* Hugging Face Spaces
* Streamlit Community Cloud

### 📚 Documented Decisions

Notebooks and project documentation explain **why** a particular approach was chosen — not simply **what** was used.
